# 牙周图表OCR优化方案总结

## 问题分析

### 问题1：多类型数据自动区域划分

**需要识别的数据类型：**
| 数据类型 | 符号/格式 | 字段映射 |
|---------|----------|----------|
| PD（探诊深度） | 小数 0-15mm | `pd_XX_b`, `pd_XX_l` |
| BOP（出血指数） | 数字 0-4 或 +/- | `bop_XX_b`, `bop_XX_l` |
| PI（菌斑指数） | 罗马数字 I°-III° | `pi_XX_b`, `pi_XX_l` |
| Furcation（分叉病变） | 罗马数字 I°-III° | `furcation_XX_b/dp/mp` |
| Mobility（松动度） | 罗马数字 I°-III° | `mobility_XX` |

**解决方案：自动区域划分**

已实现 `EnhancedPerioOCR` 类：
- 自动检测不同数据类型的行区域
- 为每种数据类型使用专门的提取器
- 支持基于Y坐标的区域定位

### 问题2：提高识别精度

**优化路径对比：**

| 方案 | 适用场景 | 所需时间 | 预期效果 | 成本 |
|------|---------|---------|---------|------|
| **使用PPOCRLabel标注** | 少量数据，快速验证 | 1-2天 | 10-20%提升 | 低 |
| **模型微调** | 大量数据，长期使用 | 1-2周 | 30-50%提升 | 中 |
| **数据增强** | 提高模型鲁棒性 | 随训练进行 | 5-10%提升 | 低 |
| **后处理优化** | 修正识别错误 | 1-3天 | 15-30%提升 | 低 |

**推荐策略：渐进式优化**

```
第一阶段：后处理优化（立即实施）
  ↓
第二阶段：PPOCRLabel标注（数据积累）
  ↓
第三阶段：模型微调（数据量充足后）
```

## 立即可实施的优化

### 1. 后处理规则优化

```python
# 修复常见识别错误
def post_process_ocr(text):
    # 罗马数字修正
    text = text.replace('l', 'I').replace('|', 'I')

    # 小数点识别
    if re.match(r'\d+[:：]\d+', text):
        text = text.replace(':', '.').replace('：', '.')

    # 度数符号修正
    text = text.replace('o', '°').replace('0', '°')

    return text
```

### 3. 上下文一致性检查

```python
# 检查PD值的合理性
def validate_pd_value(value, context_values):
    """根据周围值判断当前值是否合理"""
    if value > 10:  # 超出正常范围
        # 如果周围值都很小，可能是误识别
        avg_neighbors = sum(context_values) / len(context_values)
        if abs(value - avg_neighbors) > 5:
            return avg_neighbors  # 使用邻居的平均值
    return value
```

## 模型微调指南

### 何时需要微调

**✅ 需要微调：**
- 识别准确率 < 80%
- 特殊符号识别率 < 70%
- 手写数字识别率 < 85%
- 有500+标注数据

**❌ 不需要微调：**
- 使用PPOCRLabel标注后效果满意
- 数据量 < 100

### 快速微调流程

```bash
# 1. 准备数据
python prepare_training_data.py --label_txt Label.txt --output_dir training_data/

# 2. 训练识别模型（CPU模式）
cd C:\Users\lazymark2\Documents\perio_OCR/PaddleOCR
python tools/train.py \
    -c configs/rec/ch_ppocr_v2.0/rec_ch_ppocr_v2.0.yml \
    -o Global.pretrained_model=./pretrain_models/ch_PP-OCRv4_mobile_rec_train/best_accuracy.pdparams \
    -o Train.dataset.data_dir=../training_data/ \
    -o Train.dataset.label_file_list=../training_data/train.txt \
    -o Global.epoch_num=30 \
    -o Optimizer.base_lr=0.0005

# 3. 导出模型
python tools/export_model.py \
    -c configs/rec/ch_ppocr_v2.0/rec_ch_ppocr_v2.0.yml \
    -o Global.pretrained_model=./output/ch_PP-OCRv4_mobile_rec_train/inference \
    -o Global.save_inference_dir=../inference/periodontal_rec/
```
