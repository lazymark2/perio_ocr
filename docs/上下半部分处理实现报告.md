# 牙周图表OCR上下半部分处理实现报告

## 问题背景

牙周检查记录表包含上下两个半部分：
- **上半部分**：记录上颌牙齿（11-28）的数据
- **下半部分**：记录下颌牙齿（31-48）的数据

表格以"牙位"行为分隔线，上下半部分重复相同的数据行（PI、Mobility、Furcation、BOP、PD）。
