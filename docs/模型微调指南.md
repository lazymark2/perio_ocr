# 牙周图表OCR模型微调指南

## 概述

本文档说明如何为牙周图表OCR项目进行模型微调，包括：
1. 何时需要微调
2. 数据准备
3. 模型选择
4. 训练配置
5. 评估与优化

## 何时需要模型微调

### 需要微调的情况

| 场景 | 是否需要微调 | 原因 |
|------|-------------|------|
| 使用PP-OCRv5通用模型 | 否 | 对于清晰打印体效果已经很好 |
| 识别手写数字 | 是 | 手写风格差异大，需要专门训练 |
| 识别特殊符号（罗马数字、度数） | 是 | 通用模型训练数据中少见 |
| 识别医学缩写（BOP, PI等） | 是 | 需要特定领域的文本 |
| 表格结构识别 | 是 | 牙周图表有特殊的表格布局 |

### 推荐的微调策略

1. **优先使用PPOCRLabel标注数据**，而不微调
   - 成本低
   - 见效快
   - 适合数据量小的情况

2. **针对特定符号进行微调**
   - 罗马数字（I°, II°, III°）
   - 医学符号（+, -, ×）
   - 小数格式（3.5, 4.0）

3. **针对手写数字进行微调**
   - 收集手写数字数据集
   - 使用轻量级模型（mobile版）

### 3. 数据格式转换

将PPOCRLabel导出的数据转换为训练格式：

```python
import os
import json
from shutil import copy

def convert_ppocrlabel_to_training_format(
    label_txt_path,
    output_dir,
    split_ratio=0.8
):
    """
    将PPOCRLabel导出的Label.txt转换为训练格式

    Args:
        label_txt_path: Label.txt文件路径
        output_dir: 输出目录
        split_ratio: 训练集比例
    """
    # 读取标注
    with open(label_txt_path, 'r', encoding='utf-8') as f:
        lines = f.readlines()

    # 分离训练集和验证集
    total = len(lines)
    train_size = int(total * split_ratio)

    train_data = lines[:train_size]
    val_data = lines[train_size:]

    # 写入训练文件
    with open(os.path.join(output_dir, 'train.txt'), 'w', encoding='utf-8') as f:
        f.writelines(train_data)

    # 写入验证文件
    with open(os.path.join(output_dir, 'val.txt'), 'w', encoding='utf-8') as f:
        f.writelines(val_data)

    print(f"转换完成: {len(train_data)} 训练样本, {len(val_data)} 验证样本")
```

## 推荐的训练流程

### 阶段1: 快速验证（1-2天）

1. 标注50-100个样本
2. 使用mobile模型快速训练
3. 评估效果，决定是否继续

### 阶段2: 完整训练（1-2周）

1. 标注500-1000个样本
2. 使用server模型完整训练
3. 调优超参数

### 阶段3: 部署优化（3-5天）

1. 模型压缩和量化
2. 性能测试
3. 部署到生产环境
